# Honk Lotto

A tiny cartoon clicker. A goose sits on a silver egg. Scratch the egg and, once the scratch is finished, the score goes up by exactly $1. Scratch again for another dollar. Reset puts the score back to $0.

The dollars are a score. There is no account, no server, and no real money.

## Open it

Open `index.html` in a desktop browser. Double-click the file, or drag it into a browser window. No install step.

From this folder you can also serve it:

```bash
python3 -m http.server 8765
```

Then visit http://127.0.0.1:8765/

On a phone-sized window, press and rub the egg. On a desktop, click and drag across it.
